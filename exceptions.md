1.	When should you trap for exceptions?
Exceptions are used to manage errors during a program execution.  Exception must be used when the coder might go wrong while the program is running. Especially, with things like user input, dividing numbers, opening files, or converting text to numbers. In fact, handling errors correctly is super important in situation where the program has more work to do after the error. For instance, programs which ask user input, and the user input invalid information, because of the trap of exceptions the program can handle the error and ask for input again instead of crashing. In python, a try- except block is used to trap exceptions. Specifically, the try block contains the code that might cause an error, and the except block tells the program what to do if that error happens. This try-else block helps the program to handle the error correctly with crashing or producing errors.  For example, if a user enters 0 as a divisor, Python would normally cause a ZeroDivisionError, but exception handling can catch the error and allow the program to continue.
